# 마그네틱바 교반 시뮬레이션 계획

## 범위

일반 비커에서 핫플레이트 교반기로 PTFE 코팅 마그네틱바를 돌리는 실험을 대상으로 한다. 기존 `simpleRushtonMRF` 모델을 재사용하지 않는다. Rushton 임펠러·배플·밀폐 충전 원통 탱크를 가정하는 현 모델은 마그네틱바와 열린 비커 형상에 맞지 않는다.

## 모델 단계

1. **입력·기하 사전검사**: 비커 안지름, 액체 높이/부피, 마그네틱바 길이와 지름, 바닥 간극, 실제 바 회전수(또는 장비 설정 회전수), 액체 밀도·점도를 구분해 입력한다. 장비 설정 RPM은 마그네틱바의 실제 회전수로 자동 간주하지 않는다. 실제 회전수가 없으면 설정 RPM 기반 가정이라고 결과에 명시한다.
2. **저비용 유동 사례**: 비커 액체 영역과 바 형상을 따로 만들고, 실험에서 기록한 회전수로 회전영역 계산을 수행한다. 표면 와류가 관찰되지 않는 조건부터 검토한다. 출력은 속도장과 수동 추적자(passive scalar) 기반 농도 균일화 지표이며 화학 반응·침전·입자 크기는 예측하지 않는다.
3. **액면이 중요한 조건**: 와류·공기 혼입이 분석 목표이면 액체/기체 자유표면을 포함한 VOF 계산을 별도 모드로 추가한다. 계산 비용과 수치 민감도가 늘어나므로 기본 모드에 무조건 포함하지 않는다.
4. **검증**: 동일 비커·액량·바·RPM에서 색소 또는 전도도 추적자의 혼합 시간, 액면 형상이나 속도 데이터와 비교한다. 비교 전에는 시뮬레이션 결과를 실험 결과의 근거로 취급하지 않는다.

## 필요한 사용자 입력

- 비커 모델/제조사와 **실제 안쪽 지름**; 제품 자료는 규격 참고값으로만 제안하고 실험 형상과 일치하는지 확인한다.
- 실제 액체 부피 또는 액면 높이.
- 마그네틱바의 길이·지름·형상과 바닥 간극(알 수 없으면 미입력 가능).
- 교반기 설정 RPM과 실제 바 RPM을 별도 기록. 바가 미끄러져 설정 속도를 따라가지 않으면 실제 회전수가 다를 수 있다.
- 액체 조성에 맞는 밀도·점도와 온도. 검색된 순수 용매 값은 혼합 용액의 실측 물성을 대체하지 않는다.

## 근거와 제한

- 마그네틱 로드가 구동하는 무배플 탱크의 CFD 연구는 moving-reference-frame과 자유 액면 VOF를 사용했고, 150·250·400 rpm에서 접선 속도는 재현했지만 반경 속도는 과소예측되었다. 연구 자체도 모델별 오차와 계산비용을 비교한다. [Li et al., Water Science & Technology (2015), PubMed 초록](https://pubmed.ncbi.nlm.nih.gov/26465300/)
- 소형 실험 장치의 교반 CFD 연구는 마그네틱바와 바닥 사이의 작은 틈에 세밀한 격자가 필요하고, 정상상태 회전영역과 시간의존 회전영역을 장치별로 구분했다. [ACS Industrial & Engineering Chemistry Research (2024), DOI 10.1021/acs.iecr.4c01816](https://doi.org/10.1021/acs.iecr.4c01816)
- OpenFOAM의 회전 원통 검증 사례는 MRF 기반 회전 유동의 기초를 제공하지만, 비커 속 마그네틱바 형상·액면·혼합 수송을 검증해주는 사례는 아니다. [OpenFOAM 공식 rotating-cylinders 문서](https://doc.openfoam.com/2212/examples/verification-validation/laminar/rotating-cylinders-2d/)

따라서 이 문서의 단계별 계획만으로 “실험 혼합을 예측한다”고 말할 수 없다. 먼저 별도 마그네틱바 케이스를 구현하고, 기본 형상에서 solver·격자·질량 보존을 확인한 뒤, 측정 혼합 시간에 대해 모델을 검증해야 한다.
