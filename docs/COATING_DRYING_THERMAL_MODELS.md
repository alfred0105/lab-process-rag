# 코팅·건조·열처리 모델 연결

## 데이터 흐름

1. 코팅 계산에서 현재 주제의 실제 저장 실험(데모·계획 상태 제외)을 선택한다.
2. 코팅액 출처로 그 실험의 재료와 결과를 표시하고, 실험 ID를 스핀 코팅 계산 결과에 기록한다.
3. 저장 기록에 물성값이 명시되어 있으면 원본 경로와 함께 읽는다. 액체 밀도·점도가 없으면 인식 가능한 ethanol/MEA/water 용매 행렬만 `thermo` 패키지의 순수성분 상관식과 기본 혼합 규칙으로 추산한다. zinc acetate 염 효과는 포함하지 않으며, 이 값은 저신뢰 선별용 모델 추정으로 표시한다.
4. 스핀 코팅은 여러 RPM/지속시간 구간을 입력할 수 있다. Emslie–Bonner–Peck 식의 누적 회전 효과를 각 구간별로 적분해 종료 시점 습윤 막 두께를 건조 단계에 넘긴다.
5. 건조 모델은 선택한 휘발성 용매의 Antoine 증기압 자료, 고형분 부피분율, 고형분 몰부피, 온도, 유효 기체측 물질전달계수를 사용해 용매 잔량과 막 두께의 시간 변화를 계산한다.
6. 열처리 모델은 승온·유지·냉각 프로그램과 온도 이력을 표시한다. 승온 속도 0은 즉시 설정 온도에 놓는 단계 입력이며, 냉각 속도는 생략할 수 있다. 재료별 활성화에너지와 전지수 인자가 사용자가 제공될 때만 1차 Arrhenius 전환율을 계산한다.
7. 비휘발 부피분율이 없으면 습윤막 두께 계산은 실행할 수 있지만 건조막 두께는 계산하지 않는다. 이론상 산화물 수율을 실제 비휘발 부피분율 대신 사용하지 않는다.

## 모델 및 출처

- 스핀 코팅 액막 얇아짐: Emslie–Bonner–Peck 회전막 모델. 이 구현은 Newtonian 액체와 이상적인 균일막 가정의 1차 근사다.
- 혼합 용매 건조: NatLabRockies의 [SolVap/SolVap_StarTer](https://github.com/NatLabRockies/SolVap)에서 사용한 lumped-parameter mixed-solvent evaporation model (LPMSEM) 접근을 수치 어댑터로 연결했다. 해당 소프트웨어는 [NatLabRockies 연구 소프트웨어 기록](https://research-hub.nlr.gov/en/publications/solvapstarter-solvent-evaporation-graphical-user-interface-swr-26/)에 소개돼 있다. 용매 증기압 계수는 모델 원본의 NIST Chemistry WebBook 참조 링크를 함께 제공한다.
- 용매 행렬 물성 추산: [ChEDL thermo](https://github.com/CalebBell/thermo) 패키지의 순수성분 상관식 및 기본 혼합 규칙을 사용한다. 이 앱은 현재 ethanol/MEA/수화수 용매 행렬을 구성하며 zinc acetate 이온·착물 및 용해에 따른 부피 변화를 계산하지 않는다. 따라서 최종 코팅액의 실측 물성으로 취급하지 않는다.
- 스핀 코팅에서 용매 증발과 액막 얇아짐이 함께 작용하는 근거: [Shimoji, A New Analytical Model for Spin Coating Process with Solvent Evaporation (1987)](https://doi.org/10.1143/JJAP.26.L905), [Bornside et al., Modeling of Spin Coating (1987)](https://experts.umn.edu/en/publications/modeling-of-spin-coating/).

## 범위와 제한

- 건조는 일정한 온도와 유효 물질전달계수 아래의 균일한 1차원 막 근사다. 기류, 혼합용매 비이상성, 활동도, 표면장력 구배/Marangoni 흐름, 막 내부 확산, 겔화 및 기판 흡수는 풀지 않는다.
- 증발 종료 시간은 사용자가 입력한 유효 물질전달계수에 민감하다. 이를 장비별 상수 또는 보편적인 예측치로 간주하지 말고, 질량 감소·건조 시간·막 두께 측정치로 보정해야 한다.
- 적용 온도가 원본 Antoine 자료 범위를 벗어나면 계산을 거부한다.
- 열처리 프로파일은 프로그램 온도다. 시료 열지연, 실제 시료 온도, 분위기/산소분압, 열분해·상변화·결정화·치밀화 및 막 수축은 모델링하지 않는다.
- 기록에 농도와 밀도만 있고 몰부피·단위·혼합 용매 조성이 없으면 임의 환산하지 않고 사용자 입력을 요구한다.
- 용매행렬 추산값은 zinc acetate가 포함된 최종 용액의 측정 물성이나 정밀 예측이 아니다. 실제 점도·밀도 측정값이 입력되면 모델 추산보다 측정값을 우선 사용한다.
- 모델 결과는 측정값이 아니며 실험 설계 참고용 계산이다. 재료/공정별 검증 전에는 결과를 실험 사실로 사용하지 않는다.

## Gemma 자동 입력 연결

코팅 시뮬레이터에서 저장된 실제 실험을 고르고 **Gemma 자동 입력**을 누르면 Gemma가 기록의 재료·공정 항목을 시뮬레이터 필드와 연결한다. Gemma는 기록의 값과 출처 경로만 선택하고, 서버가 그 경로가 원본 기록에 실제 있는지 확인한 뒤 단위를 환산한다. 구분 가능한 zinc acetate dihydrate/ethanol/MEA 조성은 결정론적 계산기로 농도, MEA:Zn 몰비, 이론상 ZnO 질량을 다시 계산한다. 코팅 반복 횟수는 사용자가 지정하며 기본값은 5회다.

이 연결은 원본 실험 기록을 수정하지 않는다. 저장 기록에 없는 밀도·점도는 용매행렬 물성 추산기로 채우되, 추정 상태와 염 성분 제한을 함께 표시한다. 기판 치수와 건조 질량전달계수는 직접 측정·입력해야 한다. 비휘발 부피분율이 없으면 습윤막 계산까지만 실행하고 건조막 두께는 비워 둔다. Gemma가 반환한 수치는 시뮬레이터에 직접 신뢰하지 않으며, 서버가 저장 기록의 원본 경로와 수치/단위를 확인한 경우에만 입력한다.
