# 문헌 공정 데이터 예비 백테스트

작성일: 2026-10-28

## 요약

문헌 CSV의 7개 데이터셋과 125회 보고 실행을 공정군별로 유지한 채, 공정 입력값에서 결과값을 맞히는 단순 ridge 회귀 기준선을 시험했다. 같은 입력 조건을 반복한 행은 모두 같은 검증 묶음에 넣어, 같은 조건의 반복 측정이 학습과 평가 양쪽에 나뉘는 누수를 막았다.

- 전체 125회 실행은 **111개 고유 조건 조합**으로 이루어져 있다. 반복 조건 행은 14개다.
- 고유 조건이 8개 이상인 9개 결과 시리즈에서 고정 ridge 회귀의 leave-one-condition-group-out MAE가 training-mean 기준선보다 낮았다.
- 단, 이는 각 문헌 데이터 안에서 가능한 관계 신호를 살펴본 **예비 기준선**이다. 제품 안의 자동 추천·시뮬레이션이 잘 작동한다는 검증은 아니다.
- 현재 `/api/designs`는 근거 검색 결과만 반환하고, `/api/process-changes/analyze`는 기록 조건과 문헌 검색을 제공한다. 결과를 예측하거나 다음 공정 조건을 추천하는 결정/시뮬레이션 모델은 구현되어 있지 않다.

## 반복 가능한 검사

실행:

```bash
cd <project-root>
backend/.venv/bin/python scripts/evaluate_benchmark_backtest.py
```

스크립트: [`scripts/evaluate_benchmark_backtest.py`](../scripts/evaluate_benchmark_backtest.py)

방법:

1. `dataset_id`별로 따로 처리했다. 서로 다른 재료·공정·분야를 한 모델에 섞지 않았다.
2. 동일한 입력 인자 조합의 모든 반복행을 하나의 fold에 묶고, 고유 조건 조합 하나씩을 통째로 제외해 예측했다.
3. 각 학습 fold 안에서 숫자형 인자를 표준화하고 범주형 인자를 one-hot 처리했다.
4. 고정 정규화 강도 λ=1인 ridge 회귀를 학습 평균 예측과 비교했다. 하이퍼파라미터를 결과에 맞춰 조정하지 않았다.
5. 오차는 각 결과의 원 단위 MAE다. 서로 다른 결과 단위의 MAE는 합산하거나 직접 순위화하지 않았다.

## 결과

| 공정군 / 결과 | 실행 / 고유 조건 | Ridge MAE | 학습 평균 MAE | 기준선 대비 MAE 감소 |

| Co-ZnO 광촉매 / ciprofloxacin 제거율 | 30 / 25 | 9.59 퍼센트포인트 | 13.95 퍼센트포인트 | 31.3% |
| CuFeO₂ 수열 박막 / 광전류 밀도 | 25 / 25 | 0.0116 mA/cm² | 0.2641 mA/cm² | 95.6% |
| MgAl-LDH 공침 / 유도 시작 시간 | 8 / 8 | 1.44 min | 3.14 min | 54.3% |
| MgAl-LDH 공침 / 생성량 | 8 / 8 | 5.27 g | 10.09 g | 47.8% |

| PMMA 재료압출 / 인장 강도 | 25 / 25 | 6.46 MPa | 10.02 MPa | 35.5% |

| 물히아신스 무촉매 수열액화 / 바이오오일 수율 | 13 / 9 | 2.88 퍼센트포인트 | 6.47 퍼센트포인트 | 55.5% |

LDH 용액 부피는 논문이 보고한 공정 관련 수치다. 생성량처럼 최적화할 실험 성과와 동일한 목표라고 해석하면 안 된다.

Cu-Mn 산화물 공침은 결과 열이 여러 개지만 **고유 조건이 4개뿐**이다. 조건 하나씩을 제외하면 학습에 남는 서로 다른 조건이 3개뿐이므로 수치 점수는 계산만 가능할 뿐, 일반화 성능 증거로 보지 않았다.

## 결과 해석과 한계

- 9개 시리즈 모두 이 간단한 회귀가 평균 기준선보다 낮은 MAE를 냈다는 점은, 일부 논문 데이터에 조건-결과 신호가 들어 있음을 보여준다. 하지만 이는 앱의 추천 성공률이나 실험 성공확률이 아니다.
- CuFeO₂의 95.6% 개선은 특히 조심해야 한다. 이 논문은 25개 설계점에서 반응값이 거의 선형으로 움직이며, 보충자료 ANOVA에는 pure-error 자유도가 0으로 보고되어 있다. 작은 실험 설계에 아주 잘 맞은 것이 새로운 실험실이나 다른 조건에서도 유지된다는 뜻은 아니다.
- Co-ZnO 중앙점 반복은 표에 네 자리까지 모두 동일한 측정값으로 실려 있다. 반복값의 산포를 알 수 없어 오차·재현성을 충분히 평가할 수 없다. 반복 조건을 한 fold로 묶어 누수는 방지했지만, 원문의 반복 결과 자체가 갖는 한계는 남는다.
- LDH는 8개 고유 조건뿐이라 예비 결과일 뿐이며, Cu-Mn은 4개라 정량적 일반화를 검증하기 어렵다.
- 한 논문 안의 설계 범위에서 행 하나씩 가린 검증이다. 새 재료, 다른 장비, 다른 연구실, 설계 범위 밖 조건으로의 전이 검증은 아니다. 논문에 나온 수치만으로는 실험 성공/실패 라벨이나 예측확률을 만들 수 없다.

## 판단

문헌 자료는 **동일 공정군 안에서 조건과 결과를 연결하는 초기 회귀 기준선**을 시험하기에는 유용하다. 현재 코드에 들어 있는 분석 과정은 문헌 표를 찾아 보여주고 관측값을 요약하는 단계까지이며, 성능이 검증된 다음 조건 추천기는 아직 없다. 그러므로 이번 결과는 “데이터에 신호가 있는가”에 대한 초기 확인이지, “우리가 만든 AI 추천 과정이 잘 작동한다”는 합격 판정이 아니다.

추천기를 구현한 뒤에는 이 스크립트의 조건 묶음 holdout을 재사용하고, 예측 오차와 기준선 비교를 표시하며, 별도 논문·후속 실험 데이터로 외부 검증해야 한다. 성공확률을 표시하려면 먼저 성공 기준을 연구자와 함께 정하고, 반복 실험 및 충분한 실패/성공 사례를 확보해야 한다.
