# XRD 피크 기반 결정상 후보 검색

## 동작 흐름

1. 기존 XRD 분석기가 원본 패턴의 `2θ–intensity` 데이터에서 국소 최대 피크를 계산합니다.
2. 사용자는 대상 결정상에 들어갈 원소 조합(최대 4개)을 지정합니다. 이미 후보식을 알고 있으면 고급 입력에서 최대 5개 화학식을 직접 지정할 수 있습니다.
3. 원소 검색은 Crystallography Open Database(COD)의 공개 검색 API를 사용합니다. 검색에는 원소 기호만 전달하고 원본 측정 파일은 로컬에 둡니다.
4. 검색 결과 중 최대 30개 구조 CIF를 가져와 pymatgen XRDCalculator로 같은 파장과 관측 구간의 참조 회절 패턴을 계산합니다.
5. 관측 피크와 기준 피크의 일치 점수, 관측 피크 커버리지, COD 구조 ID, 가능하면 DOI를 함께 보여줍니다.

## 결과 해석 제한

표시 점수는 관측 피크 위치와 기준 피크 위치의 커버리지 기반 패턴 매칭 점수이며, 물질일 확률이나 확정 동정률이 아닙니다. 회절 강도 프로파일 기반 정합이나 정량 상분율도 아닙니다. 데이터베이스에 없는 상, 혼합상, 비정질 성분, 배향, 기기 영점/파장 오차, 격자 변형, 피크 중첩, 품질이 낮은 입력 파일은 순위에 영향을 줍니다. 현재는 단일 결정구조 기준 패턴과 비교하며 다상 정량, Rietveld refinement, 화학 결합 상태 분석은 하지 않습니다.

따라서 이 기능은 후보를 좁히고 확인할 COD/논문 출처를 찾는 보조 도구입니다. 최종 동정은 원본 패턴, 장비 설정, 시료 조성, 표준물질 및 전문가 검토와 함께 수행해야 합니다. 원소 조합이 불명확하면 자동 검색 결과도 믿을 만한 후보 집합을 만들 수 없으므로 검색 전에 대상 결정상의 예상 원소를 확인해야 합니다.

- [pymatgen XRDCalculator](https://pymatgen.org/pymatgen.analysis.diffraction.html): CIF 구조에서 계산 분말 XRD 패턴 생성
