# 시약 투입량 기반 pH 추정

## 기능

실험 실행 입력 화면의 `pH 시뮬레이션`에서 공정 단계를 고르고, 초기 물 부피와 산·염기 시약의 농도·투입 부피, 물질량(mmol), 또는 순수 시약 질량(g)을 입력하면 추정 pH를 계산한다. 사용자가 `예상값을 실험 기록에 추가`하면 결과를 `Estimated solution pH · [단계명] (model estimate)`로 저장하고, 계산 모델·입력·가정을 관찰 기록에 함께 남긴다. 실제 측정 결과와 계산 추정값은 라벨에서 구분한다.

API: `POST /api/simulations/ph/estimate`

## 적용 범위

현재 버전은 25 °C 이상 용액의 이상 희석 용액 근사를 사용하고, 다음 항목만 모델링한다.

- 강산·강염기: HCl, HNO3, NaOH, KOH
- 이양성자 산: H2SO4의 두 번째 해리 포함
- 약산·다양성자산: CH3COOH, H3PO4
- 약염기: NH3/NH4+ 평형
- 탄산염: NaHCO3, Na2CO3와 탄산계 평형

계산은 온도에 따른 pKa 변화, 활동도 계수, 침전, 금속 이온 가수분해, 착물 형성, 기체 교환, 반응속도를 고려하지 않는다. 그러므로 금속 전구체가 포함된 공침액이나 고온·고압 수열 반응 내부의 실제 pH를 예측한다고 해석하면 안 된다. 지원하지 않는 시약은 임의로 추측하지 않고 거부한다.

## 사용 시 주의

1. 예상 pH는 측정값이 아니다. 실제 pH를 기록하려면 교정된 pH 전극으로 측정한다.
2. 계산 결과를 실험 기록에 추가하면 값에 `model estimate`가 표시되고, 입력과 한계가 함께 저장된다.
3. 비이상 용액, 금속 이온, 침전이 중요한 조성은 PHREEQC 등 검증된 열역학 자료를 갖춘 별도 엔진과 해당 조건의 검증이 필요하다. 현재 앱의 pH 모듈은 PHREEQC 연결이 아니다.
