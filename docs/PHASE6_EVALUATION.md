# Phase 6 Evaluation

필수 비교 축: synthetic-only V1/V2/tree baseline, frozen-backbone full-depth head, layer-wise early exit, decision-only 대 conditional explanation. Same frozen 24-row synthetic test에서 Phase 6 final head는 accuracy 0.333 / Macro F1 0.196, Phase 5 V1 0.500 / 0.350, V2 0.667 / 0.355, weighted V2 0.667 / 0.591, HistGradientBoosting 0.417 / 0.224를 기록했다. 이번 synthetic split에서는 Phase 6 head가 V2 및 weighted V2보다 낮았고 더 낫다는 주장을 하지 않는다. Early exit rate는 calibration threshold 없음으로 0%, 모두 28/28 layers를 수행했으며 p50 107.4ms 대 full-depth 107.5ms로 연산/속도 이득이 입증되지 않았다. 19개 valid runtime 사례에서 raw action accuracy는 0.211 (synthetic only)였다. decision-only는 생성 토큰 0개(109.5ms), citation 없는 설명은 생성 보류, 비과학 raw LM smoke는 2 token/103.3ms였으며 model output quality 평가가 아니다. 실제 연구 레이블이 없어 scientific accuracy, groundedness, 성공확률, 자동 분석 정확도를 검증했다고 주장하지 않는다. 측정 환경, 표본과 제한은 JSON 보고서가 보존한다.
